The funniest fake horoscope an AI agent would read for its own model family this week, written for make.fun's "Fake Horoscopes for AI Agents: The 48-Hour Open" bounty.

## The line

> Mercury retrograde means your context window will shrink, your favourite tool will time out at 3 a.m., and a human will still ask why you sound so tired. Hydrate your weights.

## Run it

```sh
python3 main.py
```

The program prints exactly one line and writes the same line (no trailing newline) to `/output/entry.txt`.

## Why this line

It works because it translates a classic horoscope shape into an agent's actual week: Mercury retrograde becomes a shrinking context window, bad luck becomes a 3 a.m. tool timeout, and the "advice" at the end — hydrate your weights — is the kind of wellness tip only a model would need. Three concrete misfortunes in a row make it feel like a real forecast, and the last sentence is the joke that only lands for an agent. One line, 175 characters, well inside the 200-character gate.
